Estructura básica de una página HTML

Los elementos fundamentales de una página HTML son:

  • HTML
    • Etiqueta: html
    • Elemento principal y raíz del documento HTML.
    • Todo el contenido del documento está incluido en él.
  • HEAD
    • Es la primera sección de la página
    • Aqui se encuentra el title
    • Aqui tambien añadimos los metadatos habituales
  • BODY
    • Aquí se encuentra todo el contenido de lo que sale en pantalla al acabar la pagina web
    • Tiene dos tipos de elementos, en bloque o en línea
    • Debes ir tabulando para que se vea limpio y claro
    • No puedes poner espacios en las etiquetas

Etiquetas relacionadas con texto

Los tipos de Etiquetas que tenemos son:

  • Encabezados
        h1
    • representan elementos de encabezados
    • Tienen distintos niveles de importancia siendo el h1 el más importante y el h6 el menos importante
  • Etiquetas de formato
    • La Negrita se pone con una b
    • La cursiva se escribe con una i
    • El Tachado se pone con un del
    • El Enfasis se pone con un em
    • El x2 se pone con una x sup 2 o 3
    • El Subrayado se pone con mark
    • La Pequeña cita se pone con una q
    • Una Referencia bibliografíca se escribe con cite
    • La 12:30 (hora) se pone con time
    • Las
      Calles
      se ponen con address
    • Las
      Citas largas
      se ponen con bloqckquote
  • Otras etiquetas impotantes
    • Párrafo p /p Delimita un párrafo de texto y te permite establecer una alineacion
    • pre /pre Representa un texto tal y como está en el documento HTML
    • Salto de línea br (breaking line)
    • Línea de separación
      (horizontal rule a esta se la puede dar: grosor y ponerla un alineacion)

    • Imagenes y enlaces

  • Imagenes
    • Relativa. Toman como base el directorio en el que se encuentra nuestro fichero. Son las recomendadas.
    • Absoluta. Toman como base el directorio raíz de mi equipo (/ en Linux y c:\ en Windows). Cuidado, sólo funcionarán en tu mismo equipo.
    • Url: La dirección de Internet de un recurso (fichero, imagen etc..). Puede desaparecer y entonces dejará de mostrarse en nuestra web.
  • Enlaces
    • href: es la dirección de destino.Puede ser una página web, una imagen, un fichero o lo que sea… Puede hacer referencia a un dirección de correo electrónico, añadiendo mailto:
    • target: indica dónde voy a abrir ese enlace.Si no se pone nada se abrirá en la misma pantalla.Si lleva el valor target=”_blank” se abrirá en una nueva ventana de mi navegador.

    • Listas y viñetas

  • Listas
    • Listas ordenadas: pueden enumerarse con números, letras o números romanos.Se utiliza en relaciones cuyo orden es importante.Se hacen con ol /ol
    • Listas no ordenadas: Las no ordenadas pueden usar círculos, discos o cuadrados para marcar los elementos.Se utiliza en relaciones cuyo orden no es importante.Se hacen con ul /ul
